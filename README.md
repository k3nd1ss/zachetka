# Дневник студента

Веб-приложение для учёта предметов, лабораторных, РГР и других работ, а также долгов за прошлые семестры. Удобно работает на телефоне. Регистрация не нужна.

## Как пользоваться

1. Открой **Настройки** и укажи текущий семестр.
2. Во вкладке **Предметы** добавь предмет: название, преподаватель, семестр, форма контроля, итог.
3. Внутри карточки предмета добавляй работы. Статус меняется прямо в строке работы:
   - Не сделана
   - Сделана, не сдана
   - Пробовал сдать — не приняли
   - Сдана
4. Полоска прогресса показывает, сколько работ сдано. Фильтр сверху скрывает лишние работы по статусу и типу.

## Как считаются долги

Долг — это предмет, у которого семестр меньше текущего, а итог не «сдал». Такие предметы показываются во вкладке **Долги**. Когда итог становится «сдал», предмет переходит в блок «Закрытые предметы» внизу вкладки **Предметы**.

## Где хранятся данные

Только на твоём устройстве, в хранилище браузера (localStorage). На сервер ничего не отправляется, поэтому у каждого пользователя свои данные.

Данные пропадут, если очистить данные сайта в браузере. Другой браузер или другое устройство их не увидит. Для защиты и переноса используй экспорт.

## Экспорт и импорт

- **Экспорт:** Настройки → «Экспорт в файл». Браузер скачает JSON-файл со всеми данными.
- **Импорт:** Настройки → «Импорт из файла» → выбери файл и подтверди замену. Импорт заменяет все текущие данные.

Чтобы перенести данные с компьютера на телефон, сделай экспорт на компьютере, передай файл на телефон и сделай там импорт.

## Запуск на своём компьютере

Скачай файлы и открой `index.html` двойным кликом. Установка не нужна: приложение написано на чистых HTML, CSS и JavaScript.
